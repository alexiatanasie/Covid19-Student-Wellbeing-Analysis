# Covid19-Student-Wellbeing-Analysis
This repository contains an aggregated data analysis project based on a 2020 survey dataset of 1,182 students from Delhi NCR, India. The survey explores how the COVID-19 pandemic affected students' education, lifestyle, and mental health.

## 📊 Project Overview

- **Dataset**: "COVID-19 and its impact on education, social life and mental health of students"
- **Source**: Kaggle
- **Region**: Delhi National Capital Region (NCR), India
- **Timeframe**: 2020
- **Sample Size**: 1,182 students
- **Language**: Python (Pandas, Matplotlib, Seaborn)

## 🔍 Key Analyses

- Average time spent on daily activities (online classes, self-study, fitness, sleep, social media, TV)
- Online class experience ratings across age groups
- Health issues reported during lockdown
- Correlation between social media usage and class experience
- Age group distribution and sleep habits
- Visualization: Boxplots, Bar Charts
